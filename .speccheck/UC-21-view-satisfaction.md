# UC-21 満足度をレーダーチャートで確認する: 整合性チェックレポート

- 確認日: 2026-10-11 / ブランチ: feature/app-foundation
- 対象: use-cases.md UC-21、functional-specification.md 3.3（SC-04 満足度の詳細）・4章（`GET /api/v1/viewpoints/satisfaction`）、FR-5.1・FR-6.9、dev_spec.md 5章（UC と画面・API の対応）・6章
- 結論: 基本フロー（1〜2）・代替フロー（満足度が未入力の観点がある場合の表示）・事後条件は、実装済みで、E2E・結合テスト・単体テストで通っていた。**シナリオに対する実装の不足はなかった**。ただし、**長い設備名・極端な値・画面の幅（768px・375px）の検査で、レーダーチャートと SC-04 の画面の不具合が3点見つかり**、再現するテストを先に書いて失敗を確認してから、コードを修正した。

  2. 画面の幅が狭いと、ラベルの文字が小さすぎた（768px で約 9px、375px で約 7px。768px は2列のままで、チャートが約 380px 幅に縮み、固定の表示範囲が縮小されていた）。

## 3. 今回見つかった不具合と修正

先に、長い設備名・極端な値・画面の幅の E2E を追加し、12件がすべて失敗する（または、テスト用データの投入に失敗する）ことを確認してから修正した。

### 3.1 追加した E2E（`tests/e2e/UC-21-view-satisfaction.ts` の末尾）

画面の幅 3 種（1280px・768px・375px）× 4 ケース = 12 件。

| ケース | 設備名                            | 値                                                |
| ------ | --------------------------------- | ------------------------------------------------- |
| 1      | 日本語 200 文字（上限）           | 全観点が 5（総合 5.0・正常）                      |
| 2      | 区切りのない英字 200 文字（上限） | 全観点が 1（総合 1.0・異常）                      |
| 3      | 日本語 200 文字（上限）           | 全観点が未入力（不明。ラベルがすべて2行）         |
| 4      | ハウス1                           | 1・5 が交互に混在し、最後の観点だけ未入力（不明） |

各テストの検査（`expectPageFits`・`expectRadarIntact`）:

- ヘッダーの「対象の設備」のラベルが潰れず、選択欄・対象の設備名がページの幅に収まる。観点別の表の行が潰れない。横スクロールがない。
- レーダーチャートの全ラベルが、SVG の枠の中にあり（切れない）、互いに重ならず、画面上の文字の大きさが 10px 以上。
- チャート本体（外側の多角形とラベル）の左右・上下の余白の差が、幅・高さの 3% 以内（偏りがない）。チャートの幅が、SVG の枠の幅の 8 割以上（余計な隙間がない）。

## 5. 画像の目視確認

`test-result/e2e/` の `uc21-radar`・`uc21-missing`・`uc21-user-b`・`uc21-extreme-{1280,768,375}-{ja-all5,ascii-all1,ja-none,mixed-missing}` を確認した。

- 1280px（全観点 1・異常、設備名が英字 200 文字）: チャートが、左のパネルの中で左右・上下に偏らず、ラベル（データ活用度合い・環境適応性など）が切れず、重ならない。目盛りの数字が、上のラベルと重ならない。右の表と並ぶ。設備名は、ページの幅の中で折り返される（余計な隙間は、設備名が1行の長さを超えるときの「対象:」の改行のみ）。
- 1280px（一部が未入力）: 未入力の軸（耐久性・データ活用度合い）は点がなく、ラベルの下に「（未入力）」が2行で出て、左側の他のラベルと重ならない。多角形は入力済みの軸だけを結ぶ。
- 768px（全観点 5、日本語の設備名 200 文字）: 1列になり、チャートが中央に大きく表示され、ラベルが読める。ヘッダーの設備選択欄は広がらず、設備名は折り返される。表は幅いっぱい。
- 375px（全観点未入力・全観点 1・混在）: ラベルが 10px 以上で、切れず、重ならず、左右に偏らない（未入力の2行ラベルも重ならない）。チャート自体は小さい（ラベルが長いため。半径は約 70px）が、観点別の表（下）に値が全て出る。ヘッダー・表・パネルに、はみ出し・潰れはない。
- 懸念として残る点: 375px では、チャートが小さい（ラベルの長さと文字の読みやすさの兼ね合い）。値の読み取りは、直下の表で補える。
