## 4. 本調査で見つけた不足と、変更内容

### (1) 注意・正常での通知の E2E（手順5）

- `tests/e2e/UC-07-input-missing-data.ts` に「注意になる値（温度 27℃）を保存すると、未読の通知が作られる。正常になる値（温度 20℃）では作られない」を追加。温度 20℃ を保存 → 結果が「正常」・通知の一覧に環境適応性が0件 → 同じ画面から、別の計測日時（11:30）で温度 27℃ を保存 → 通知の一覧に、ハウス1・環境センサー1の「注意」が各1件、を確認する。
- 本体コードの変更なしで成功した。

### (2) 対象の設備の選択肢・計測日時の既定の E2E（手順1・2）
