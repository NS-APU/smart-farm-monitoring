# UC-19 判断基準を編集する: 整合性チェックレポート

- 対象: use-cases.md UC-19、functional-specification.md 3.12（SC-13 判断基準の編集）・4章（判断基準の API）、FR-5.7・5.8、dev_spec.md 4章 No.10・5章（UC と画面・API の対応）、6章
