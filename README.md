# いちご収獲ロボットに対応したハウス整備モデルの第三者評価のしくみ

## 概要

農業現場（圃場・施設）の状況をデータとして継続的に把握し、本システムによる判断支援と人による確認（Human-in-the-Loop）を組み合わせて、栽培・運用の意思決定を支えるスマート農業向けモニタリングシステムです。

プロジェクト全体の詳細は [docs/00_project/project-overview.md](./docs/00_project/project-overview.md) を参照してください。

## 目的

- 現場のデータを集めて見える化し、状況を素早く正しく把握できるようにする
- システムによる分析・提案で、判断にかかる負担や見落としを減らす
- 重要な判断は人が確認・承認できる仕組みにして、安心して運用できるようにする
