## 1. 収穫精度

| 項目 | 内容 |
|------|------|
| 観点名 | 収穫精度 |
| 対象 | 収穫ロボット（収穫の品質） |
| 目的 | 傷つけずに、取り残さず、売れる果実を収穫できているかに気づく |
| 指標・データ | **メトリクス**<br>・可販果率（%）= 100 − ((誤収穫数 + 果実損傷数) ÷ 収穫数 × 100)<br>・取り残し率（%）= 取り残し数 ÷ (収穫数 + 取り残し数) × 100<br>・認識精度（%）= 100 − 取り残し率<br>・果実損傷率（%）= 果実損傷数 ÷ 収穫数 × 100<br>**データ項目**: 収穫数、果実損傷数、誤収穫数、取り残し数<br>**取得方法**: 手動入力（収穫数はロボットデータからの自動取得も想定）<br>**ダッシュボード表示（主要）**: 可販果率、認識精度。それ以外は詳細画面に表示する |
| 判断基準 | ・可販果率: 90%以上 → 正常 / 80%以上90%未満 → 注意 / 80%未満 → 異常<br>・認識精度: 90%以上 → 正常 / 80%以上90%未満 → 注意 / 80%未満 → 異常<br>・最終ステータス: 可販果率と認識精度のうち悪い方<br>・不明: 収穫数・果実損傷数・誤収穫数・取り残し数のいずれかが未取得、または収穫数 = 0 |

| 見つかった異常への対応 | 注意・異常は通知する（UC-10）。農作業者が原因を確認して調整し（UC-05）、結果を記録する（UC-06）。診断メッセージ・推奨アクションの内容は TODO: 定める |
