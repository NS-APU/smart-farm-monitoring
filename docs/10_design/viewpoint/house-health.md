# ハウスの健全性の観点

目的: スマートハウスの環境の健全性を評価する観点（環境適応性）と、その判断基準を定める。共通のルールは [evaluation.md](./evaluation.md)、記載形式は [viewpoint-overview.md](./viewpoint-overview.md) を参照する。

> **基準の位置づけ**
> - 判断基準の数値は、構想時のプロトタイピング要件（`work/functional.requirements.md`）の既定値を仮に採用したもので、根拠は未確認。**暫定の値で運用し**、評価関係者に確認して見直す（決定。[ADR-0017](../adr/0017-evaluation-rules.md)。[rfp.md](../requirements/rfp.md) の Q-007。確認事項は #209）
> - 判断基準は運用で変更できる（FR-5.7）。ここに書くのは既定値

## 1. 環境適応性

| 項目 | 内容 |
|------|------|
| 観点名 | 環境適応性 |
| 対象 | ハウス（環境センサーが計測する環境） |
| 目的 | ロボットの作業・作物にとって、環境が適した範囲から外れていることに気づく |
| 指標・データ | **データ項目（メトリクスとして直接評価する）**: 温度（℃）、湿度（%）、照度（lx）、CO2濃度（ppm）<br>**取得方法**: 環境センサー（ファイルサーバー経由の自動取り込み）＋手動入力（環境情報）。両方を評価の対象とする<br>**ダッシュボード表示（主要）**: 温度、湿度、照度、CO2濃度<br>**短期視点**: 最新の環境観測値（観測時刻を併記）。**長期視点**: 選択した期間の平均 |
| 判断基準 | ・温度: 10℃以上25℃未満 → 正常 / 0℃以上10℃未満、25℃以上35℃未満 → 注意 / 0℃未満、35℃以上 → 異常<br>・湿度: 40%以上80%未満 → 正常 / 30%以上40%未満、80%以上90%未満 → 注意 / 30%未満、90%以上 → 異常<br>・照度: 20,000lx以上40,000lx未満 → 正常 / 10,000lx以上20,000lx未満、40,000lx以上50,000lx未満 → 注意 / 10,000lx未満、50,000lx以上 → 異常<br>・CO2濃度: 800ppm以上1,000ppm未満 → 正常 / 200ppm以上800ppm未満、1,000ppm以上3,000ppm未満 → 注意 / 200ppm未満、3,000ppm以上 → 異常<br>・最終ステータス: 4指標のうち最も悪いもの<br>・一部の指標のみ取得できている場合は、取得できた指標だけで判定する<br>・不明: 4指標のすべてが未取得 |
| 基準の根拠 | 構想時の既定値（暫定）。根拠（作物・ロボットの適正環境の出典）は未確認で、評価関係者に確認する（Q-007。確認事項は #209）。**昼夜で値が変わる指標（照度・温度）も、全時間帯に同じ基準を使う**（決定。[ADR-0017](../adr/0017-evaluation-rules.md)）。夜間の照度（0 lx 近くになると推定）や冬の夜温で、注意・異常になる可能性があり、利用者が画面から基準を調整して避ける。実データで頻発したときは、見直す |
| 見つかった異常への対応 | 注意・異常は通知する。農作業者がハウスの環境を確認して調整する（UC-05）。本システムはハウスの環境制御を自動では行わない（[goals.md](../../00_project/goals.md)）。内容は TODO |
| 確認事項 | 構想時の要件の範囲表記（例: 0〜10℃）は、境界を「以上」「未満」（半開区間）に読み替えて記載した（決定。[ADR-0017](../adr/0017-evaluation-rules.md)）。読み替えの意図は、確認する（#209）。TODO: 環境センサーの機種・取得方式（Q-004）。ロボットの姿勢（転倒など）は、ステータスコードのカテゴリで扱う（収穫速度・耐久性のステータス判定。決定。[ADR-0017](../adr/0017-evaluation-rules.md)）。環境センサーの夜間の記録の有無は、確認する（#193） |
