# プロジェクト概要

## 背景

本プロジェクトは、秋田県立大学からの業務委託として実施するものであり、国立研究開発法人農業・食品産業技術総合研究機構 生物系特定産業技術研究支援センターが推進する「次世代スマート農業技術の開発・改良・実用化」の一環である。
主なテーマは、イチゴ収穫ロボットとスマートハウスを組み合わせた次世代施設園芸モデルの実用化促進である。人手不足が進む施設園芸分野において、収穫作業の自動化と遠隔での環境制御を実現し、現場への普及を支援する。

## 概要

収穫作業の自動化や遠隔環境制御の実現に向け、次の二つの観点から研究開発を支援する。

1. **収穫ロボットの第三者評価の仕組み構築**
   イチゴ収穫ロボットを実際の施設園芸環境で運用することを想定し、以下の観点でロボット運用の信頼性・実用性を客観的に評価する仕組みを構築する。
   - 安全性
   - 稼働率・連続運転性能
   - 障害発生時の復旧容易性
   - メンテナンス性
   - 代替作業手段の確保

   あわせて、農業ロボット分野における信頼性指標(MTBF・MTTR等)や、ヒューマン・イン・ザ・ループ(HITL)方式の国内外の先行事例を調査し、実運用を見据えた評価モデルの確立を目指す。

2. **環境制御に向けた情報基盤の整備**
   スマートハウスにおける環境制御の高度化を目的として、以下を実現できる環境を整備する。
   - ハウス内の環境情報の収集
   - 環境状態の可視化
   - 遠隔制御に必要な情報の把握

   これにより、将来的な遠隔監視・遠隔制御や、自動最適化型の栽培管理に向けた基盤づくりを進める。

## 現状の課題

- 施設園芸分野では人手不足が進行しており、収穫作業の省力化が求められている。
- イチゴ収穫ロボットの実運用における課題や改善点を、客観的に評価する仕組みが確立されていない。
- ロボット導入前に、運用リスクや必要な保守体制を把握することが難しい。
- スマートハウスの環境データを、遠隔監視・遠隔制御や栽培管理に十分活用できる情報基盤が整っていない。

## 目指す姿

人手不足が進む施設園芸分野において、収穫ロボットとスマートハウスを組み合わせた持続可能な生産モデルを実現し、スマート農業技術の社会実装と普及拡大を後押しする。
具体的には、以下の状態を目指す。

- ロボットの実運用における課題や改善点を客観的に評価できる。
- 導入前に運用リスクや必要な保守体制を把握できる。
- スマートハウスの環境データを活用した効率的な栽培管理が可能になる。
- 収穫作業の省力化と生産性向上につながる。
- イチゴ収穫ロボットの実用化・普及モデルの確立に貢献できる。
