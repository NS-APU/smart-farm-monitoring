# ゴール

## システムの目的

ロボットとハウスの状態をデータで「見える化」し、異常や不調に農作業者が早く気づいて対処できるようにすることで、ロボットとハウスの安定稼働を支える。

### 実現すること

1. **データを集める**
   ロボットおよびハウスの環境情報を、センサー等からの自動収集、または農作業者による手動入力で取得する。
2. **データを蓄積する**
   取得したデータを一元的に保存し、時系列で振り返れるようにする。
3. **分析結果を伝える**
   蓄積したデータを分析し、結果をダッシュボードで農作業者に分かりやすく提示する。
4. **人の対応につなげる**
   ダッシュボードをきっかけに、農作業者がロボットやハウスの状態を確認して復旧・調整を行う。これがヒューマン・イン・ザ・ループ(HITL)の入口となる。

### 位置づけ

本システムは、ロボットやハウスを自動で制御するものではなく、人の判断と対応を支援する情報基盤である。

## 成功条件

実際の圃場で本システムを運用し、データにもとづくフィードバックが農作業者の対応を通じて、ロボットとハウスの安定稼働の継続に役立つこと。

具体的には、次の三点を満たすこと。

1. **現場で使える**
   実際の圃場で、ロボットおよびハウスのデータを継続的に収集・蓄積できている。
2. **人に伝わる**
   分析結果がダッシュボードを通じて農作業者に届き、状況の把握や対応判断に使われている。
3. **安定稼働につながる**
   フィードバックを受けた農作業者のリカバリ(HITL)により、ロボットとハウスの稼働が継続的に安定している。
